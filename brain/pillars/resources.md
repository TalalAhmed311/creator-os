# Pillar: Useful Resources

**Format:** Instagram carousel (1080×1350) · **Vibe:** clean, themed, save-worthy.

## Carousel structure
1. **Slide 1 = hook.** Number + who it's for + outcome: "7 free resources to actually understand LLMs".
2. **One resource per slide:** name, one-line value (why it's worth it), who it's for, tag (Free / Paper / Course / Repo), small logo/screenshot if available.
3. **Last slide = save/follow CTA.** "Save this for later · follow for more".

## Rules
- Only include what you'd genuinely recommend. 5–8 items is the sweet spot.
- Every resource verified: link live, still maintained (repos: commits in the last ~12 months), actually useful.
- One-line value = a concrete benefit, not a description ("Builds a GPT from scratch in 2 hours" > "A video about GPT").
- Don't repeat resources already shared (check `memory/long-term/pillars/resources.md`).
- Themes live in `brain/carousel-themes/`. Text is always rendered by HTML/CSS — never by an image model.

## Interview questions (strategist, ≤3)
1. What resources (or what topic should I research)?
2. Who are they for?
3. Which theme? (math-wall, blueprint, terminal, clean-light, or propose 3)
